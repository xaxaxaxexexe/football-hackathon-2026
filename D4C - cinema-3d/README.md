# Билет с видом на поле (команда D4C)

Веб-сервис покупки билетов на матч: стадион → матч → схема сектора → 3D-вид на поле с места (Three.js) → покупка. Данные в MySQL.

Визуальная адаптация кинопроекта под кейс «Билет с видом на поле»: таблицы и API прежние (`cinemas` — стадионы, `halls` — сектора, `movies` — матчи, `sessions` — расписание, `sofa` — ложи), в `db/seed.js` стадионы, матчи и цены 700 / 1200 / 3500 ₽, в 3D вместо экрана поле 105 × 68 м с трибунами и прожекторами. Стадионы и клубы вымышленные.

## Запуск
1. Установите MySQL 8 (или MariaDB 10.5+) и Node.js 18+ (нужен глобальный `crypto.randomUUID`, Node 19+; в Node 18 запускайте с `--experimental-global-webcrypto`).
2. `cp .env.example .env` и впишите `DB_USER` / `DB_PASSWORD`.
3. `npm install`
4. `npm run seed` — создаст БД, таблицы и демо-данные (повторный запуск пересоздаёт всё).
5. `npm start` → http://localhost:3000 (`/?debug` — кнопки трёх контрольных мест в 3D).

## Структура
- `db/schema.sql` — таблицы. `db/seed.js` — конфигурация кинотеатров/залов/тарифов (CINEMAS, HALLS) и генератор мест, сеансов (всегда в будущем).
- `server/` — Express API; покупка в транзакции, цена берётся из БД, `UNIQUE(session_id, seat_id)` защищает от двойной продажи.
- `public/js/` — `main.js` (сценарий), `seatmap.js` (схема), `view3d.js` (3D), `sound.js` (звук с места), `api.js`.
- Схема и 3D используют одни и те же x/y/z мест из БД. Новый зал = запись в HALLS + `npm run seed`, UI менять не нужно.

## Демо (2–3 мин)
Стадион → матч → показать цены 700/1200/3500 ₽ → «Ряд 1, место 3» → «Ряд 6, место 12» → «Ряд 10, ложа 7» (сначала смотреть 3D, возвращаться к схеме) → купить → место занято, обновить страницу — билет сохранён по ссылке.

## Афиша (главная) и страницы
- `#/` — главная в стиле афиши: герой-слайдер с трейлером, вкладки «Сейчас в кино» / «Скоро», фильтр по жанрам, карточки фильмов (рейтинг, возраст, цена «от», форматы), боковая колонка, кинотеатры.
- `#/movie/ID` — страница фильма: описание, реакции, сеансы по кинотеатрам и дням → выбор места, трейлеры, похожие фильмы. `#/trailers` — все трейлеры. `#/soon` — скоро в кино. `#/cinemas` — прежний сценарий «кинотеатр → сеанс».
- API: `GET /api/movies`, `GET /api/movies/:id`. В `movies` добавлены поля `year, country, rating, age, premiere, trailer_url`: после обновления выполните `npm run seed` заново.
- Видео трейлера: впишите в `movies.trailer_url` ссылку `https://www.youtube.com/embed/ID` или на `.mp4` — иначе показывается демо-экран.
